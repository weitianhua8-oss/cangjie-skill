# 3D Knowledge Card Skill v2.0

## Purpose
Create educational 3D knowledge cards from English-thinking analysis. The card is not a decoration image; it is a visual explanation of the underlying English logic.

## Mandatory Workflow
Before generating any image:

1. Use English Thinking Word Explainer workflow:
   - review and verify concept
   - core origin/core meaning
   - core mental image
   - underlying logic
   - meaning growth tree
   - real scenes
   - collocations
   - confusing-word comparison
   - boundary checks
   - examples
   - memory hook
   - knowledge-tree connection

2. Build knowledge architecture:
   - Decide whether content needs multiple cards.
   - Never compress all meanings into one crowded image.
   - Complex words follow the BE model.

## BE Model Structure

### Card 1: Core Essence
Answer: What is this word fundamentally?

- one central metaphor
- one spatial relationship
- one memory sentence

### Card 2: Meaning Growth
Answer: How do different meanings grow from the core?

- show branches from the core image
- avoid direct Chinese meaning lists

### Card 3: Real Application
Answer: How is it used?

- common scenes
- example sentences
- typical patterns

### Card 4: Boundary Comparison
When needed:

- compare similar words
- explain why English separates them

### Card 5: Knowledge Network
Connect related concepts and vocabulary.

## Visual Rules

- Warm white background
- 3D rounded cards
- Dark blue titles
- Clear hierarchy
- Large readable text
- Mobile readable
- One card explains one logic
- Use arrows for direction/relationship
- Use containers for inside/outside concepts
- Use boundaries for differences
- Use state boxes for states
- Use action scenes for ongoing processes

## Character Rules
Characters are semantic helpers, not decoration.

Allowed roles:
- action performer
- beneficiary/target
- explainer

Do not:
- randomly change character roles
- add meaningless characters
- use negative gestures/actions

Use pointing gestures with index finger only.

## Quality Check Before Generation

Confirm:
- English thinking analysis completed
- core image selected
- knowledge structure separated
- text amount is appropriate
- no tiny unreadable text
- examples match the concept
- visual metaphor matches the logic
